# Desktop workflow expansion

User request: build all five proposed features. Preserve the Signal visual language, existing work, authenticated IPC and lock behavior. Native egui application; no web redesign. All features must be reachable with visible controls and keyboard navigation.

1. Universal command palette: extend Super+Space launcher to installed apps, current windows, settings sections and desktop commands, plus bounded local filename search. No shell interpretation of user queries. Prefix app matches rank first; typed searches distinguish result kinds. Enter executes selected result, arrows navigate, Escape closes, clear resets selection/results. File search is local, nonrecursive symlink traversal, bounded by depth/entries/results/time, skips hidden/build directories, asynchronous and stale-safe. Open files through xdg-open with argv. App matches focus a running instance when available; context menu still pins.
2. Session restore: explicit save/restore controls in Settings > Session and palette. Save only installed desktop IDs, window workspace/display placement and terminal working directories/layout. Never persist terminal contents, commands, passwords or arbitrary executables. Owner-only atomic bounded JSON storage with version and validation. Restoration launches recognized installed apps at most once per saved slot, does not duplicate existing instances, reports missing applications, recreates terminal directories and restores placements after windows appear using bounded retry. No automatic launch at login without a user setting; explicit Restore fulfills initial release. Preserve pins in existing config. Unsaved app documents and terminal processes are not resurrected.
3. Per-monitor docks: independent dock state on each shell viewport, shared pins, current-display running windows, primary shortcuts retained, keyboard dock shortcut routed to pointer's display. Compositor overlay/input uses that display's shell surface and local coordinates. Lock and screenshot suppression apply to every dock; disconnected displays drop state. Extend protocol backwards compatibly with screen-indexed dock/placement commands as necessary.
4. Desktop health: Settings > Health read-only screen with connection status, native helper availability, log locations and recent bounded log excerpts, refresh and open logs buttons. Background checks, explicit unknown/missing/failure states, no privileged operations, no secret-bearing logs in diagnostics exports.
5. Terminal search: Ctrl+Shift+F in active pane opens search bar; plain terminal input stays unchanged when closed. Search full configured scrollback, case-insensitive literal matching, next/previous wrap, match counter, highlighted current match, scroll to match, copy matched text, clear, Escape returns terminal focus. Search consumes typing/Enter/Escape while open; IME-safe. Bounded work consistent with terminal budgets. Tests cover history, Unicode, wrap and keyboard isolation.

Verification: tests for policies, parsing and lifecycle, egui headless interaction where feasible, workspace build/tests and premium static audit. Existing four Unix-bind tests fail in this sandbox; preserve strict failures. Real DRM, multiple physical displays and suspend remain hardware acceptance work. Do not install or publish the running desktop.
