# Remediation validation, 15 October 2026

The code fixes and validation tooling are implemented in the current working tree.
This record does not certify a hardware release or the existing APT binaries.

## Implemented

- New Wi-Fi connections use NetworkManager D-Bus with credentials in the message body. No subprocess receives the password. Payload tests cover SSID/secret punctuation, open and WEP settings, and invalid input. A failed activation removes only the profile created by that request so a password can be retried.
- Music IPC limits clients to 16, requests to 16 KiB, reads to 60 seconds, writes to 5 seconds, and operations to 30 seconds. Tests cover framing, malformed input, slow writers, stalled operations, partial input during broadcasts and admission-slot release.
- The music socket has a private owned directory, mode 0600 and an endpoint lock. Tests cover private-directory creation, unsafe directories/symlinks, protection of ordinary files, and exclusive startup ownership. The shell uses the same fallback path and sends an idle heartbeat. Binding remains after Spotify initialization, because the shell uses a listening socket as its readiness signal.
- Shell frame updates live in `shell/src/runtime.rs`; playback state and lifecycle live in `music/src/service.rs`; transport and socket policy are separate modules. Existing behavior tests are retained.
- `scripts/verify.sh` runs shell syntax checks, the complete test suite and the workspace build. Rust CI saves its log and an exact source snapshot. The website has a read-only PR build workflow and a pinned pnpm version. Hardware acceptance remains explicitly separate.
- `scripts/validation-snapshot.py` includes tracked, untracked and deleted source paths plus content hashes and executable bits, preserving the pre-existing working tree. Tested stable fingerprints, inclusion of untracked files and detection of content changes in a disposable repository.

pnpm cache/operation-lock location is read-only, and registry fetches fail with

versions or TypeScript checks were weakened to hide this failure. The new CI check
must install from the frozen lockfile and complete the build on a networked runner.
